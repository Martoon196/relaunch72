# Property Predator AI reuse contract

**Status:** binding implementation rule for Growth HQ planning and future AI rails.

Property Predator already owns useful AI configuration, knowledge and proven
outputs. Growth HQ must reuse that owned work before creating a replacement.
This applies to the Affiliate Stash content engine and the founder's existing
Property Predator Content Marketer, Image Maker, Social Media Manager and other
specialist ChatGPT configurations.

## Non-negotiable rules

1. **Inventory before invention.** No new specialist prompt, customer avatar,
   image recipe or brand-voice pack is approved until the corresponding
   existing source has been inventoried.
2. **Port the owned brain, not private platform state.** Import founder-supplied
   instructions, knowledge files, examples and approved outputs. Never scrape a
   private ChatGPT account, copy conversation history without review or assume a
   ChatGPT share link is an application API.
3. **Affiliate Stash stays authoritative for its current strengths.** Reuse its
   approved brand-trained content, artwork and generators through the scoped
   company-content adapter. Growth HQ adds workflow, versioning, approval,
   scheduling and conversion context; it does not silently fork the source.
4. **One versioned Brand Brain.** Customer avatars, offers, claims, tone,
   exclusions, visual direction and reference knowledge are stored once with
   immutable versions. Specialist profiles reference a reviewed version rather
   than maintaining conflicting copies.
5. **Specialists remain distinct.** Content Marketer, Image Maker and Social
   Media Manager keep their own role instructions, tools and output contracts
   while sharing the same approved brand and avatar knowledge.
6. **Proven outputs become regression fixtures.** Representative good and bad
   examples are retained as evaluation fixtures so prompt/model changes cannot
   quietly damage brand voice, factuality or channel quality.
7. **Every artifact is attributable.** Store the specialist profile version,
   Brand Brain version, source-content version, prompt/template version, model,
   generation time and resulting immutable content hash.
8. **AI creates proposals, not unreviewed effects.** Generated copy, images,
   replies and schedules enter the existing draft/version/approval boundary.
   No generation path may publish, message or spend directly.

## Founder-supplied inventory for each existing bot

- bot name and purpose;
- current private instructions;
- uploaded knowledge/reference files;
- customer avatars and offer definitions it relies on;
- useful conversation starters or workflow steps;
- three to ten examples that are strongly on-brand;
- examples of unacceptable output and why;
- required tools/actions and any external data source;
- ownership/licensing confirmation for imported material.

Secrets, personal chat history, customer-private data and provider credentials
are excluded from this inventory.

## Target Growth HQ shape

- A **Brand Brain registry** owns reviewed knowledge and avatar versions.
- A **Specialist Profile registry** owns role instructions and output schemas.
- The existing **company-content adapter** supplies approved Affiliate Stash
  content and artwork without exposing customer-private data.
- An **AI execution adapter** uses application API prompts, file-search/retrieval
  and narrowly scoped tools. It does not depend on invoking a custom ChatGPT GPT
  by its consumer-product URL.
- The **content approval/version layer** receives every generated artifact.
- The **provider operation boundary** remains the only route to email, social,
  WhatsApp or other external effects.

## Delivery order

1. Inventory and ownership review.
2. Deduplicate knowledge and define the canonical Brand Brain.
3. Import specialist profiles unchanged where safe.
4. Capture golden examples and run side-by-side evaluations.
5. Connect draft-only Growth HQ tools.
6. Founder review and profile approval.
7. Only then consider a separately authorised live-provider pilot.

This contract adds no provider connection and grants no authority to publish,
message, purchase, deploy or access production customer data.
