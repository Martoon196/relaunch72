# Onboarding Prop Invest UK and Key Properties UK (RL72 content system)

This prepares two brands for researched blogs and social drafts using only existing RL72 mechanisms. Nothing in this package creates a brand, enrols an organisation, sets a budget, confirms a profile, connects an account, installs a plugin or publishes. Those are owner or operator actions on live systems, listed below in order.

RL72 marketing work is paused for this delivery. Property Predator's voice, offers and commercial claims must not be imported into either brand.

## Owner and operator steps (in order; none performed by this package)

1. **Organisation.** Martin selects a workspace in the verified owned organisation that should own each brand, then uses Content system → **Add brand**: "Prop Invest UK" with `https://propinvestuk.co.uk`, and "Key Properties UK" with `https://keypropertiesuk.co.uk`.
   - Check the brand list first so a duplicate isn't created.
   - Creating a brand requires an organisation owner.
2. **Production packs.** Automatic activation of the eight approved packs applies only if that organisation is already enrolled with evidence (`docs/rl72-boosters-0.1.1.md`).
   - Enrolment is an operator action. Do not infer it from a brand name.
   - The individual pack and "all off" controls remain on Production rules.
3. **Documents.** Upload each brand's own approved documents as knowledge, extract the profile, review it, then **Confirm profile**. Never share documents across the two brands.
   - Prop Invest: the training document, audience personas, the partnership sales-page brief, and the brand/image guide.
   - Key Properties: a voice/ICP/claims brief still needs writing.
4. **Budgets.** Set monthly model-token, search and image allowances in Publishing settings. The default 0 cannot spend.
5. **Prop Invest WordPress.**
   1. Install `relaunch72-publisher-1.0.0.zip` and check its SHA-256.
   2. Choose a dedicated Author as "Publish as".
   3. Create the connection key.
   4. In RL72, Setup → **Connect: WordPress** with site `https://propinvestuk.co.uk`; paste the key into the secure field (never into chat or email).
   5. Run the check. Expected: Rank Math mode, root `investor-insights`.
   6. Approve the editorial root `/investor-insights` and categories chosen from the site's existing six.
   7. Run the plugin's Public output check and resolve any warning.
6. **Social.** In the scheduler, set each brand profile's external ID to that brand's RL72 workspace ID, so RL72 discovery offers only that profile.
   - Complete the RL72 OAuth handoff and bind accounts. Binding requires the verified `account.connected` receipt.
   - Daily and monthly caps stay 0 (off) until the owner sets them.
   - Never bind another brand's account.
7. **Key Properties website.** Decide whether and where a blog lives, and how the site is hosted or deployed. Then connect the matching existing destination type. Until then, Key Properties gets social drafts only.
